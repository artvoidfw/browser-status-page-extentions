# 🌟 VoidTab - Müasir Yeni Səhifə (New Tab) Brauzer Genişlənməsi

JavaScript və Tailwind CSS ilə hazırlanmış, təmiz, minimalist və zərif yeni səhifə (New Tab) brauzer genişlənməsi.

---

## 🚀 Brauzerə (Brave, Chrome, Edge) Necə Əlavə Etməli?

1. Brauzerinizdə ünvan sətrinə daxil edin:
   - **Brave üçün:** `brave://extensions`
   - **Chrome üçün:** `chrome://extensions`
   - **Edge üçün:** `edge://extensions`
2. Sağ yuxarı küncdəki **"Developer mode" (Tərtibatçı rejimi)** açarını aktiv edin.
3. Yuxarı solda görünən **"Load unpacked" (Paketlenməmiş yüklə)** düyməsini sıxın.
4. Açılan pəncərədə bu layihə qovluğunu (**`browser-status-page-extentions`**) seçin.
5. Brauzerdə yeni səhifə (`Ctrl + T`) açın və zövq alın! 🎉
